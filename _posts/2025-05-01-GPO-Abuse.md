En este artículo hablaremos de como abusar del Group Policy Object **(GPO)**.
Antes de empezar con lo anterior mencionado, debemos saber que es el GPO y como funciona, esto es muy sencillo ya que el GPO son una serie de configuraciones que definen como tiene que comportarse el sistema para un grupo definido de usuarios. Podemos usar esto para movernos lateralmente o escalar privilegios.

Para enumerar los derechos del GPO podemos usar el siguiente comando:
```powershell
Get-NetGPO | select displayname
```
